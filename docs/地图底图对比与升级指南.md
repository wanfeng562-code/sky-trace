## 已完成的代码迁移

| 范围 | 当前实现 |
| --- | --- |
| 实时地图与历史回放 | 共享天地图 `vector` / `imagery` / `terrain` 样式构建函数 |
| 底图选择与故障处理 | 移除原境外地图供应商及自动回退，缺 Key 或访问失败给出提示 |
| 地名与边界 | 中文使用官方注记，英文使用本地 GeoNames 地名点；停用第三方行政边界及境外地形叠加 |
| 区域筛选 | 台湾省等列于中国下级；bbox 用于近似筛选与定位，取消自绘行政边界高亮 |
| 字体 | 本地打包有许可证的字形资源，保留中文本地生成 |
| 发布资源 | Vite 改用 `public-app`，旧 `public/geo` 不随构建发布 |
| 代理与监控 | 移除旧境外瓦片代理；地图调用额度在供应商控制台查看 |
| 文档及配置 | 新 Key 与审图号变量、部署步骤及材料重制说明 |

MapLibre 是渲染引擎；国界来自天地图底图，中文地名来自官方配套注记，英文地名来自本地 GeoNames 点数据。保留引擎不会重新引入原底图数据。
