## 已修复的遗留与同步问题

| 问题 | 影响 | 当前修复 |
| --- | --- | --- |
| 回放返回实时地图后 WebSocket 不恢复 | MapView 被 KeepAlive 保留，回放主动断开连接，返回时不会再次执行 onMounted | onActivated 恢复连接、调整画布尺寸并刷新地名 |

- 在运行后端实际提交 501 条核验地名，分批请求成功；核验记录随后清理，不保留测试名称。
- 实际浏览器未出现页面异常、API HTTP 错误或控制台错误；地图请求域名为天地图，捕获的底图响应均为 200。
- 三种天地图样式切换保留英文地名与航班图层；台湾省、香港、澳门地名属性统一为 `CN`。回放读取真实本地历史快照，并支持中文注记恢复。
- 236,046 条聚居地记录、概览与 110 个分片的 SHA-256 均与清单一致。生产资源不包含旧地图服务地址/代理路径或 `geo` 边界目录。
- 桌面入口通过 Python 语法检查；本次未启动桌面 GUI，不将其视为完整桌面端验收。

## 仍需同步或补全

### 正式前端仍是旧构建

只读检查 `https://sky-trace.pages.dev/`：当前引用 `/assets/index-BRvOb76y.js`，与本地新构建不同。其主包仍包含旧地图供应商与 DataV 逻辑，未检测到天地图或本地英文地名功能。本次仅重启本地服务并生成完整新构建，未发布云端；正式站点不能作为本地地图迁移已上线的证据。

### 正式后端地址返回 404 HTML

按当前生产环境中的后端地址检查 `/api/v1/health` 与 `/api/v1/tiles/stats`，均收到 HTTP 404、`text/html`，标题为 `Not Found`。本次不能确认云端 FastAPI 服务正常运行；需核实 AutoDL 实例、内部服务端口/入口映射与生产环境地址，不能仅凭本地健康结果推断线上正常。

### 审图号尚未配置

开发、生产环境均已配置自己的天地图 Key，但三种底图的审图号变量均为空。需要针对实际调用服务核实编号后配置，不编造或挪用编号。软件登记截图、说明书和代码节选也需使用最终新版本替换旧材料。

### 英文业务面板仍有部分中文

本次补齐了主航班列表和标记列表的遗漏，底图中英文切换与统计/回放核心文案已接入语言字典。高级筛选、静态行政区名称、枢纽详情、航班详情和部分天气/时刻表文字仍有中文，未宣称全站已经全部翻译。GeoNames 地名的拉丁字母回退也不是天地图中文注记的逐条官方英文翻译。

### 构建体积提示

生产主包仍较大，Vite 输出超过 500 kB 的分包建议；当前构建通过，属于后续性能优化项，不是地图来源或数据校验失败。
