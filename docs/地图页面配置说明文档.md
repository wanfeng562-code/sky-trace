# Sky-Trace 地图页面配置说明

更新日期：2026-10-16。实时地图与历史回放统一使用天地图官方 WMTS 底图，中文使用配套官方注记，英文叠加本地 GeoNames 地名点。MapLibre GL JS 继续负责地名、航班与天气图层渲染。生产数据服务暂时停用，开发环境仍可使用本地后端。

## 服务选择

本次迁移采用天地图。自然资源部地理信息管理司的[官方说明](https://www.cgs.gov.cn/tzgg/tzgg/202504/t20250424_805126.html)列出了可以在线免费调用的基础地图及其他 API 服务；应用的实际额度、域名限制和授权范围应以开发者控制台为准。高德的[官方 JS API 说明](https://lbs.amap.com/api/JavaScript-api/summary)说明非商业用途可免费使用，商业用途需先取得商用授权。

天地图提供全球底图，已有 MapLibre 的飞机、轨迹、天气网格及回放可以复用。高德、百度等方案需要同时核查 SDK 授权及航班坐标转换，因此本次不切换渲染引擎。

## 本地配置

在[天地图开发者平台](https://lbs.tianditu.gov.cn/)选择适合浏览器调用地图服务的应用类型，取得自己的 Key，配置开发与生产访问域名。不要使用他人的 Key 或免 Key 接口。

在 `client/.env.development.local` 配置开发环境；生产环境使用 `client/.env.production.local` 或部署平台环境变量：

```ini
VITE_TIANDITU_KEY=你的天地图应用Key
VITE_MAP_DEFAULT_STYLE=vector
# 2026-10-13 从国家天地图官网与在线地图实际核实
VITE_MAP_APPROVAL_NUMBER=GS（2026）4921号
```

开发环境配置本地 `VITE_API_BASE_URL` 和 `VITE_WS_URL`；生产目前配置 `VITE_BACKEND_ENABLED=false`，并将两个旧服务地址清空。完整模板见 `client/.env.example`。Key 和审图号变化后须重启开发服务器，生产环境须重新构建。Vite 的 `VITE_*` 变量会编译到浏览器资源中，须在天地图控制台限制授权域名；本地环境文件不要提交。

如果三种底图的审图号不同，分别配置 `VITE_MAP_APPROVAL_VECTOR`、`VITE_MAP_APPROVAL_IMAGERY`、`VITE_MAP_APPROVAL_TERRAIN`；这些值优先于统一的 `VITE_MAP_APPROVAL_NUMBER`。统一编号只能在已确认适用于所启用服务时使用，不得挪用其他地图或版本的编号。

当前编号来自[国家天地图官网](https://www.tianditu.gov.cn/)的 `window.mapdrawingApprovalNumber` 与[在线地图](https://map.tianditu.gov.cn/)实际显示，保存在 `client/src/data/mapApproval.json`；三种当前底图均采用此编号，环境变量可覆盖。编号标识原底图来源，不代表自定义英文注记与业务叠加获得独立审图；服务更新时应重新核实编号。

## 底图与坐标

| 样式 | 底图 | 配套注记 | 地图源最大级别 |
| --- | --- | --- | --- |
| `vector`（默认） | `vec_w` | `cva_w` | 18 |
| `imagery` | `img_w` | `cia_w` | 18 |
| `terrain` | `ter_w` | `cta_w` | 14（地图可继续放大） |

使用[官方地图服务](https://lbs.tianditu.gov.cn/server/MapService.html)的 HTTPS WMTS 接口，`TILEMATRIXSET=w`，瓦片大小 256。中文保留配套官方注记，英文隐藏该注记层并叠加本地地名点，基础地图始终使用天地图。代码不改写官方国界或行政界线，不使用自绘边界补丁，也未调整栅格重采样。`_w` 是墨卡托瓦片，不能混用 `_c` 经纬度网格。

航班原始经纬度继续保留；不会将接入国内服务等同于必须施加 GCJ-02 偏移。MapLibre 会投影经纬度来叠加业务图层。实际接入后应以机场坐标和近机场轨迹核验叠加位置。

## 本地英文地名

在底图面板选择 English 后，实时地图和历史回放均使用本地英文地名；恢复简体中文后，重新显示天地图官方中文注记，不重建航班数据源。英文数据加载或校验失败时恢复中文注记并显示提示。

数据来自 [GeoNames 官方下载](https://download.geonames.org/export/dump/)，按 [CC BY 4.0 许可](https://www.geonames.org/export/)使用。本次完整保留 `cities500.zip` 中 236,046 条有效城市、城镇及其他聚居地记录，并用 `alternateNamesV2.zip` 匹配现行英文别名：48,034 条有明确的英文语言别名，其余 188,012 条使用原始拉丁字母名称或音译。这不是逐条翻译天地图中文注记，也不保证覆盖全球所有聚居地、街道、道路、山川、POI 或与天地图同级别一一对应。

国家文字采用显式名单，共 195 条；台湾省、香港特别行政区、澳门特别行政区是中国下的 3 条地区文字，分别显示 `Taiwan Province, China`、`Hong Kong SAR, China`、`Macao SAR, China`。对应聚居地的 `countryCode` 统一为 `CN`；上游地区代码作为兼容信息保留。所有记录均为 WGS84 地名点，未导入 GeoNames 或其他来源的边界几何。国家文字坐标只是显示锚点，不代表行政中心、边界或领空。

完整数据保存在 `client/public-app/place-labels/`，拆为 110 个非空的 20° 网格文件；6 级以下加载全球概览，6 级及以上加载当前视野需要的网格。记录按人口和聚居地类别设定最小显示级别，文字自动避让；小城镇、社区和历史聚居地需进一步放大才能显示。按需加载、视野筛选和避免重叠不会删掉数据文件中的记录。文件名包含内容哈希，读取时验证 SHA-256，并缓存最多 32 个文件，地图归属控件显示 GeoNames 与许可证链接。

更新数据时从 GeoNames 官方下载并保存为下列文件名：

```text
out/map-validation-20261012/geonames-cities500.zip
out/map-validation-20261012/geonames-alternateNamesV2.zip
out/map-validation-20261012/geonames-countryInfo.txt
out/map-validation-20261012/geonames-readme.txt
```

然后执行：

```powershell
python -X utf8 scripts/build_place_labels.py --input-dir out/map-validation-20261012
```

构建脚本同步生成公共目录及 `client/src/data/placeLabelManifest.json`，清单记录输入文件哈希、输出哈希、记录数量和名称来源统计。新数据可替换上述数字，应重新运行地图检查并构建；只更新其中一份清单会导致部署版本不一致。原始下载文件位于忽略的 `out` 目录，运行时不调用 GeoNames API，不需要申请其 Key 或消耗其接口额度。

## 状态与业务图层

- 未配置 Key：显示中性画布及明确提示；地图 Key 不控制业务 API。只有启用并连接后端时才可查询航班、统计和回放，当前生产后端暂停。
- 瓦片失败、授权拒绝或限流：显示提示，保持天地图来源，不回退到其他地图。核对 Key、授权域名、服务权限和额度后刷新。
- 官方来源链接和经核实的审图号显示在地图归属控件中，控件持续展开；不要隐藏或裁掉这些信息。
- 天气网格与热力图位于地名注记下方，业务文字和本地英文地名使用本地字体。
- 区域筛选仍支持国家、省、市、区及起降机场条件。台湾省、香港特别行政区、澳门特别行政区位于中国之下；上游 ISO 地区代码只作为数据兼容标识。
- 筛选 bbox 仅用于近似范围过滤与视野定位，不表示行政边界或法定领空。停用 DataV、Natural Earth、境外 DEM 的边界/地形叠加与旧边界缓存读取，不绘制矩形行政边界。

## 发布目录与旧资源

Vite 的 `publicDir` 为 `client/public-app`，包含路由重写文件、本地字体和英文地名数据。历史的 `client/public/geo` 数据保留在仓库中供追溯，但开发与生产不再将它作为公共资源发布。旧部署的缓存和资源应随新版本发布替换，避免继续引用旧构建。

字体来自 MapLibre 官方示例资源中的 Noto Sans Regular，附 SIL Open Font License 许可证、来源提交与 SHA-256 清单。拉丁字符、标点和单位符号从本地 PBF 加载，中文由 MapLibre 使用系统字体生成。`scripts/vendor_map_fonts.py` 仅在维护时更新字体，运行应用不调用境外字体服务。

后端原 `/api/v1/tiles/maptiler/*`、`stadia/*`、`openfreemap/*` 代理已移除。`/api/v1/tiles/stats` 只返回服务元数据；天地图由浏览器直接调用，后端不会将未知用量误报为零。监控页引导查看天地图控制台。

## 验证与软著材料

```powershell
cd client
npm run test:map
npm run typecheck
npm run build
```

自动检查底图与注记配对、唯一允许的地图域名、无 Key 行为、地区归属、本地字体及旧边界资源的发布隔离，以及英文地名完整性、哈希、图层样式和跨日期线加载。后端运行 `python -m pytest tests/test_map_service.py -q` 验证旧代理未暴露。

真实服务需在配置自己的 Key 后检查：三种底图、全国与台湾地区显示、香港澳门、南海诸岛等重点区域、机场与轨迹位置、版权与审图号，以及生产域名访问授权。本次迁移不等同于地图审核或软著登记通过；按照驳回意见核对最终画面和提交材料。
